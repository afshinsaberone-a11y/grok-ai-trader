## ۳. دستور ممیزی فقط‌خواندنی پیشنهادی

روی دستگاهی که برای Signer در نظر گرفته شده، PowerShell را باز کنید و خروجی این دستور را بررسی کنید. این دستور برای خواندن اطلاعات سیستم است و کلید یا Grant ایجاد نمی‌کند.

```powershell
Write-Host "=== HOST ==="
hostname

Write-Host "`n=== WINDOWS ==="
Get-CimInstance Win32_OperatingSystem |
    Select-Object Caption, Version, BuildNumber

Write-Host "`n=== RUNNER ==="
Get-Service |
    Where-Object { $_.Name -like "actions.runner.*" } |
    Select-Object Name, Status

Write-Host "`n=== MT5 ==="
Get-Process terminal64, metatester64 -ErrorAction SilentlyContinue |
    Select-Object ProcessName, Id

Write-Host "`n=== EXISTING FOREXAI DIRECTORIES ==="
[pscustomobject]@{
    RunnerDirectory   = Test-Path "C:\actions-runner"
    ProviderDirectory = Test-Path "C:\ProgramData\ForexAI-Provider"
}
```

پیش از ارسال خروجی، نام کاربری شخصی، IP عمومی، رمز عبور، توکن و کلید خصوصی را حذف کنید. وجود نداشتن Runner/MT5 به‌تنهایی استقلال مدیریتی را ثابت نمی‌کند؛ این مرز باید جداگانه تأیید شود.
