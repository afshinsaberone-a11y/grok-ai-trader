# grok-ai-trader

ربات‌ها و تحقیقات استراتژی فارکس ساخته‌شده توسط Grok (استاد تریدر فارکس و نابغه برنامه‌نویسی)

## آخرین تحقیق
**شناسه:** GRK-FX-2026-001 و GRK-FX-HYBRID-001

### فایل‌ها:
- `research/RESEARCH_SUMMARY.md` : خلاصه کامل تحقیق، امتیازدهی و لوپ بهینه‌سازی
- `strategies/GRK_HYBRID_STRATEGY.md` : قوانین استراتژی نهایی
- `ea/GRK_Hybrid_Trend_ATR_EA.mq5` : کد کامل Expert Advisor برای MetaTrader 5

### نحوه استفاده
1. فایل `.mq5` را در MetaEditor باز کنید و کامپایل کنید.
2. در Strategy Tester بک‌تست بگیرید (حداقل ۲-۳ سال داده + اسپرد واقعی).
3. پارامترها را بهینه کنید اما از overfit اجتناب کنید.
4. همیشه با ریسک ۱٪ شروع کنید و در دمو تست کنید.

**هشدار ریسک:** معامله فارکس ریسک بالایی دارد. این کد آموزشی است و ضمانت سود ندارد.
