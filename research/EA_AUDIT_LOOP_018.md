# لوپ تحلیل و رفع ایراد قرارداد — GRK-FX-2026-018

ربات نمی‌تواند «بدون ایراد بازار» شود؛ فقط قرارداد ایمنی قابل بستن است.

ایرادهای نسخه‌ی ۳.۱۱ که در ۳.۱۲ بسته شد:
- فقط سمت خرید فعال بود → فروش ترند و رنج اضافه شد
- لات همیشه حداقل حجم بود → سایز از ریسک ۰.۵٪ و فاصله استاپ
- ضرر روزانه فقط اینپوت بود و اجرا نمی‌شد
- فیلتر خبر وجود نداشت → بلک‌اوت تقویم اقتصادی
- ورود روی هر تیک → فقط کندل جدید H1
- بافر اندیکاتور بدون ArraySetAsSeries

## حلقه
1. اسکن `ea/` و `strategies/` برای الگوهای ممنوع (گرید، مارتینگل، بدون استاپ، تضمین سود).
2. بررسی نشانگرهای اجباری در EA هسته: ریسک ۰.۵٪، فیلتر اسپرد، فیلتر خبر، سقف ضرر روزانه.
3. اگر `--fix` باشد فقط پچ‌های امن اعمال می‌شود.
4. تکرار تا ۵ بار یا تا صفر شدن یافته‌های سطح بالا.
5. خروجی JSON در `research/EA_AUDIT_LOOP_018.json`.

```bash
python research/project_repair_loop.py --root . --max-loops 5
python research/project_repair_loop.py --root . --fix
```

ایراد باقی‌مانده غیرقابل حذف با کد:
بازار رژیم عوض می‌کند و edge تاریخی از بین می‌رود. لوپ فقط ایمنی قرارداد را نگه می‌دارد.
