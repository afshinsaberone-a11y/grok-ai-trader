# EA Audit Loop 018

تاریخ: 2026-09-23
هدف: تحلیل استاتیک قرارداد ایمنی ربات تا نقط قراردادی برطرف شود.
این لوپ سود زنده را تضمین نمی‌کند.

## ایرادهای پیداشده در v3.11 و اصلاح v3.12
1. فقط ورود Buy در ترند → اضافه Sell هم‌جهت Daily/EMA
2. رژیم RANGE پیاده‌سازی نشده بود → ورود رنج با RSI و باند
3. ضرر روزانه فقط input بود → محاسبه سود/زیان روزانه و قفل ورود
4. حجم لات مینیمم بود، نه ریسک 0.5٪ → محاسبه حجم بر اساس ATR و ریسک
5. فیلتر جلسه نداشت → لندن/نیویورک
6. فیلتر شوک ATR نداشت → رژیم SHOCK
7. فقط یک موقعیت → حداکثر دو موقعیت

## اجرا

```bash
python research/project_repair_loop.py --root .
```
