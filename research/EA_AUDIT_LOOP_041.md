# لوپ ممیزی قرارداد ربات — 041

هدف لوپ تضمین سود نیست. هدف این است که قرارداد ایمنی در کد EA نقض نشود.

```bash
python research/project_repair_loop.py --root .
python research/project_repair_loop.py --root . --fix --max-loops 8
```

بررسی‌های اجباری روی `ea/GRK_Hybrid_Regime_EA.mq5`:

- وجود ریسک درصدی و سقف ضرر روزانه
- سقف معاملات روزانه و کول‌داون
- توقف بعد از باخت‌های متوالی
- گیت اسپرد نسبت به ATR
- فیلتر رژیم ADX (روند / رنج / گذار)
- فلت جمعه و بلاک دوشنبه
- بلک‌اوت خبر
- یک پوزیشن در نماد
- ممنوعیت صریح grid / martingale / average-down
- عدم استفاده از لات ثابت بدون محاسبهٔ فاصلهٔ استاپ

اگر موردی کم باشد، `--fix` فقط کامنت قرارداد و نسخه را هم‌تراز می‌کند؛ منطق معاملاتی را بی‌دلیل عوض نمی‌کند.
لوپ fail-closed است: نبود فایل EA یعنی شکست ممیزی.
