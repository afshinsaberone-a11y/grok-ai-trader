## ترکیب خلاقانه GRK-REGIME-035

سه رژیم + گیت شوک + HTF + جلسه + جمعه + بلک‌اوت خبر + بلاک دوشنبه صبح + Donchian برای رنج:

1. **TREND:** ADX ≥ 25 و EMA20/50 هم‌جهت + Daily EMA50 → پولبک به EMA20
2. **RANGE:** ADX ≤ 18 → لمس باند بولینگر + RSI اشباع + نزدیکی Donchian20، هدف میانه
3. **TRANSITION / SHOCK:** 18 < ADX < 25 یا کندل ≥ 2.5×ATR → بدون ورود جدید / بستن + کول‌داون

ایمنی ثابت: ریسک 0.5٪، ضرر روزانه 2٪، حداکثر 3 معامله/روز، حداکثر 2 باخت متوالی، فیلتر هزینه/ATR، جلسه لندن/نیویورک، بلک‌اوت جمعه و خبر، یک موقعیت، بدون گرید/مارتینگیل.
