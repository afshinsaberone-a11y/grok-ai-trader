## ترکیب خلاقانه GRK-REGIME-031
سه رژیم + گیت شوک + HTF + جلسه + جمعه + بلک‌اوت خبر + بلاک دوشنبه صبح:

1. **TREND:** ADX ≥ ۲۵ و EMA20/50 هم‌جهت + Daily EMA50 هم‌جهت → پولبک به EMA20
2. **RANGE:** ADX ≤ ۱۸ → لمس باند بولینگر + RSI اشباع، هدف میانهٔ باند
3. **TRANSITION یا SHOCK:** ۱۸ < ADX < ۲۵ یا کندل ≥ ۲.۵×ATR → بدون ورود جدید / بستن + کول‌داون
