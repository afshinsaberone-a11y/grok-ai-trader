# GRK-REGIME-SWITCH-003

سیستم دو مغزی: ترند فشرده + بازگشت محدود + حالت شوک.

## تشخیص رژیم (بار بسته شدن H1 یا H4)

```
ADX14 >= 22 and abs(EMA200_slope) > slp_min  -> TREND
ADX14 < 18 and BBwidth in mid-quartile       -> RANGE
ATR14 / SMA(ATR14,50) >= 1.8                 -> SHOCK
else                                         -> NEUTRAL (no trade)
```

## TREND
همان قوانین `GRK_HYBRID_STRATEGY.md`:
- همسویی EMA50/200
- اسکوییز اختیاری برای شکست
- یا پولبک به EMA20
- ریسک ۱٪، استاپ ۱.۶ ATR

## RANGE
- لمس باند پایین + RSI14 < 30 + قیمت بالای EMA200 → لانگ تا میانه باند
- لمس باند بالا + RSI14 > 70 + قیمت پایین EMA200 → شورت تا میانه
- اگر ADX حین پوزیشن از ۲۲ رد شد → خروج فوری (رژیم عوض شد)
- ریسک ۰.۷٪ (وین‌ریت بالاتر، R کوچکتر)

## SHOCK / رویداد قرمز
- پوزیشن جدید ممنوع
- پوزیشن باز: استاپ را سفت نکن؛ سایز جدید صفر
- بعد از ۲ کندل H4 با ATR نرمال → بازگشت به تشخیص

## مدارشکن مشترک
- ضرر روزانه ۲٪
- ضرر هفتگی ۵٪
- حداکثر همبستگی: یک جهت روی EURUSD و GBPUSD همزمان ممنوع

## آنچه این ترکیب درست می‌کند
- ترندفالو دیگر در رنج حساب را نمی‌ساید
- بازگشت به میانگین دیگر چاقوی ترند را نمی‌گیرد
- خبر و انفجار ATR از ورود احمقانه جلوگیری می‌کند

## آنچه هنوز ریسک است
- تأخیر تشخیص رژیم (یک تا چند کندل)
- آستانه‌ها باید روی داده خارج از نمونه پایدار بمانند؛ بهینه نکنید تا مرگ
